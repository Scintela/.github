# 安全策略 / Security Policy

## 报告漏洞 / Reporting a Vulnerability

**请勿通过公开 Issue 报告安全问题。Do not report security issues via public issues.**

- 📧 **Scintela@outlook.com**
- 或使用 GitHub 私密漏洞报告 / Or use GitHub's Private Vulnerability Reporting

我们会在 72 小时内确认收到,并在修复后公开致谢报告者(除非你希望匿名)。
We will acknowledge receipt within 72 hours and credit you after the fix unless you prefer to remain anonymous.
