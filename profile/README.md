## 我们在做什么 / What we do

边缘AI最大的痛点是碎片化:同一个模型,在 RK3588、Jetson、ESP32、手机 NPU 上是完全不同的工具链、完全不同的性能——而目前没有一个社区能系统地回答:

> **哪个模型、量化到什么程度、在哪块板子上、什么功耗下,能跑到什么性能?**

Scintela 用社区众包的方式回答这个问题:

- 🧮 **Scintela Matrix** —— 核心资产:模型×硬件适配矩阵,一行一条实测数据,谁贡献谁署名 → [`Scintela/matrix`](https://github.com/Scintela/matrix)
- 🔬 **可复现基准** —— 每条数据附环境快照与复现命令,被独立复现的记录升级为「已验证 ✓」
- 📚 **端到端教程** —— 从训练、量化到部署到具体硬件的踩坑实录(建设中)
- 💡 **硬件点亮榜** —— 没人测过的板子挂在许愿单,认领跑数、点亮署名
